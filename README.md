## 1. Object Detection under Unified Retraining

<!-- Source: Tables 1.10, 2.4, 3.1, and 4.8 in Response Letter-TCSVT-30733-20260930.docx. -->

To compare the enhancement methods under unified experimental settings, all methods were retrained using the same 20,000-image subset selected from the COCO2017 training set and the same clean/compressed image pairs generated by VTM-12.0 under the all-intra configuration with YUV 4:2:0 at QP values of 35, 37, 39, and 41. The same frozen Faster R-CNN with a ResNet-101-FPN backbone and the same object-detection-oriented supervision adopted for HRPNet were used during retraining, while the original architectures of the compared enhancement methods were preserved. The parameters of the downstream task network remained fixed throughout training.

All retrained models were evaluated on COCO2017 val2017 using the same compressed test images, downstream task networks, and evaluation pipeline. AP, AP<sub>50</sub>, and AP<sub>75</sub> were reported for both object detection and instance segmentation. The corresponding results are presented in Tables 1 and 2, respectively.

HRPNet achieves the highest scores across all three metrics at QP = 40 and the highest AP<sub>50</sub> at QP = 42. EDTR obtains slightly higher AP and AP<sub>75</sub> at QP = 42 and outperforms HRPNet across all three metrics at QP = 44 and 47. Nevertheless, HRPNet consistently improves detection performance over compressed images across all evaluated QP values, demonstrating its effectiveness under unseen VVC compression levels, including those beyond the training QP range.
